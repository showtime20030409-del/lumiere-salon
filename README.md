# LUMIÈRE — AI ヘアサロン デモサイト

> **これは架空のヘアサロンのデモサイトです。** 実在する店舗ではありません。
> 掲載している店舗情報・スタイリスト・実績値（顧客満足度、診断実績など）はすべて架空のものです。
> Web制作のポートフォリオとして制作しました。

**公開URL** → https://showtime20030409-del.github.io/lumiere-salon/

---

## 概要

「AI診断 × 高級ヘアサロン」というコンセプトの、全6ページのサイトです。
フレームワークを使わず、HTML / CSS / JavaScript のみで構築しています。

| ページ | 内容 |
|---|---|
| ホーム | コンセプト、サロン紹介への導線 |
| メニュー・料金 | 施術メニューと価格 |
| AI診断 | 質問に答えると似合うスタイルを提案する診断機能 |
| スタイリスト | 在籍スタイリストの紹介 |
| ギャラリー | 施術例8点 |
| ご予約 | 予約リクエストフォーム、アクセス、FAQ |

## 使用技術

- HTML5 / CSS3 / JavaScript（ライブラリ・フレームワーク不使用）
- CSS Grid によるギャラリーのレイアウト
- IntersectionObserver によるスクロール連動アニメーション
- Google フォーム連携による予約フォーム
- GitHub Pages でホスティング

## 実装のポイント

**AI診断機能**
質問への回答からスタイルを提案する診断を、外部サービスを使わず JavaScript で実装しています。

**予約フォーム**
サイトのデザインを保ったまま、送信内容を Google フォームへ転送しています。
埋め込み型と違いサイト内で完結するため、離脱を抑えられます。
入力チェック、エラー表示、送信中の状態管理、過去日付の無効化、スパム対策を実装済みです。

**画像の最適化**
掲載画像はすべて 300KB 以下に圧縮しています。
ギャラリーの8枚はモノクロに統一したうえで、**1枚ずつ平均輝度を測って補正**し、明るさを揃えています。

**レスポンシブ対応**
デスクトップ（4列）／タブレット（2列）／スマートフォン（1列）で、
ギャラリーのグリッドが破綻せず、横スクロールが発生しないことを確認しています。
